# A 311 for agents

**Format:** article with a prototype
**Inquiry:** Authority, judgment and public life
**Worked out:** October 2026

## The argument

311 already exists as a public intake channel, which makes it the right first place to work out how agents should reach public services. An open 311 interface for agents, with a human in the loop, raises the problem the agentic flooding research describes: it could be fed abusive or bulk requests and overwhelm agencies that can't absorb them. So it needs heavy gating. The real contribution is the mental model and the schema for agent requests to a public service, which can then be tested against other scenarios.

## Builds on

The friction brief in this folder, the Tallmere 311 demo, judgment routing.

## Rule for examples

Avoid politically charged request types such as reporting encampments. Use ordinary city requests.

## Needs
