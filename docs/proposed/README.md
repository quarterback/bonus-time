# Proposed writing and talks

Ideas Ron has worked out in conversation that are not yet published anywhere. Each file is a brief: the argument, what in his existing work it builds on, the outside literature it should engage, and what it needs before it can go out as an essay, a talk, a working paper or a white paper.

Nothing in this folder is published work and none of it should be linked from the live site or cited as if it were. When a piece is published, move its brief to `docs/proposed/published/` and note where it went.

Briefs record the argument as it stood when it was worked out. Ron writes the finished pieces.
